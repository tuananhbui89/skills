# Review Coverage Map

Build this internal audit before Pass 1. Update it after every accepted change. It prevents a serial review from terminating before the document has been assessed as a whole.

## Argument map

Record the audience, promise, central model, section sequence, evidence path, case-study role, and conclusion. Mark any macro issue that changes how the reader understands the article's claim or navigation.

## Content coverage map

Create one row for every substantial heading and every independently explained mechanism. Use one status and a short reason:

| Unit | Reader job | Status | Reason / next condition |
| --- | --- | --- | --- |
| `<heading or mechanism>` | `<what readers need to understand or decide>` | `Structural change` \| `Evidence change` \| `Existing content sufficient` \| `Visual decision required` \| `Prose/table sufficient` \| `Deferred by user` | `<why>` |

An overview only covers a second unit when it can teach both without crowding, shrinking, or weakening its own lesson.

## Visual coverage map

Create a row for every system, process, comparison, hierarchy, spatial relation, data result, or failure path that prose makes hard to retain.

| Teaching unit | Status | Figure or source asset | Reason / unresolved condition |
| --- | --- | --- | --- |
| `<unit>` | `Existing figure sufficient` \| `Reuse source figure exactly` \| `Original figure required` \| `Prose/table sufficient` \| `Deferred by user` | `<figure ID, source figure, or —>` | `<why>` |

Plan an overview plus focused figures when one broad figure would overload independent mechanisms. There is no default figure cap.

## Termination check

Do not stop until every map row has a recorded disposition. A row is complete only when its accepted edit or figure is in the document, or when the user deliberately deferred it. For original figures, completion requires the drawer's rendered asset, caption, alt text, and successful embedding. For reused figures, completion requires the approved asset, credit line, caption, alt text, and provenance record.
